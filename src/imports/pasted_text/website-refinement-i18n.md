# REFINAMENTO PROFISSIONAL DO WEBSITE INFORANTUNES + INTERNACIONALIZAÇÃO i18n

O website atual da **InforAntunes já possui um design moderno, profissional, apresentável e funcional**.

NÃO quero uma reconstrução completa.

NÃO quero alterar radicalmente o design.

NÃO quero substituir a identidade visual existente.

Quero uma **segunda etapa de refinamento**, mantendo aquilo que já funciona e elevando a qualidade visual, UX, responsividade, acessibilidade, performance e consistência do projeto.

Além disso, quero implementar **internacionalização completa (i18n)** para que TODO o website possa ser utilizado em:

* 🇵🇹 Português — idioma principal
* 🇬🇧 Inglês
* 🇪🇸 Espanhol
* 🇫🇷 Francês

---

# 1. REGRA PRINCIPAL

Antes de alterar qualquer coisa, analise cuidadosamente o website atual.

Identifique:

* estrutura existente;
* componentes;
* páginas;
* rotas;
* navegação;
* hierarquia visual;
* espaçamentos;
* tipografia;
* cores;
* responsividade;
* animações;
* formulários;
* CTAs;
* imagens;
* cards;
* elementos repetidos;
* possíveis inconsistências.

Depois, faça apenas melhorias que realmente contribuam para a experiência.

### PRINCÍPIO:

> **Refinar, não reconstruir.**

O resultado deve parecer a mesma InforAntunes, porém em uma versão mais polida, sofisticada e profissional.

---

# 2. PRESERVAR A IDENTIDADE VISUAL

Manter a identidade visual atual da InforAntunes.

Preservar principalmente:

* logotipo;
* azul institucional;
* vermelho institucional;
* branco;
* tipografia atual, caso já esteja adequada;
* elementos de branding;
* estilo visual;
* fotografias relevantes;
* estrutura geral das páginas.

Não introduzir uma nova identidade visual.

Não mudar as cores da marca sem necessidade.

Se houver necessidade de pequenos ajustes de tonalidade, utilizar apenas variações extremamente próximas das cores existentes.

---

Aprimorar o design atual com foco em detalhes.

# 5. BOTÕES E MICROINTERAÇÕES

Refinar os botões existentes.

Adicionar microinterações discretas:

* hover;
* mudança de posição da seta;
* alteração suave de background;
* pequena elevação;
* focus;
* active;
* disabled.

Exemplo:

`Contacte-nos →`

No hover, a seta pode deslocar-se alguns pixels para a direita.

As animações devem ser rápidas e elegantes.

Evitar efeitos exagerados.

---

# 6. ANIMAÇÕES

O website já possui um design moderno.

Portanto, adicionar movimento apenas onde ele melhorar a experiência.

Utilizar:

* fade;
* translate;
* scale;
* reveal on scroll;
* hover;
* pequenas transições;
* parallax muito sutil quando apropriado.

As animações devem transmitir:

**qualidade + fluidez + modernidade.**

Não transformar o website em uma apresentação animada.

Priorizar performance.

Respeitar:

`prefers-reduced-motion`

---

# 7. HERO

Garantir que o utilizador entenda rapidamente:

**quem é a InforAntunes + o que oferece + qual ação pode realizar.**

# 14. INTERNACIONALIZAÇÃO — i18n

Agora implemente **i18n em TODO o projeto**.

Idiomas:

### Português

`pt`

Idioma padrão.

### Inglês

`en`

### Espanhol

`es`

### Francês

`fr`

O idioma padrão deve ser **Português**.

---

# 15. NÃO DUPLICAR PÁGINAS

Não criar quatro versões físicas de cada página.

Utilizar um único sistema de páginas/componentes.

Os textos devem ser carregados dinamicamente através do sistema i18n.

Exemplo conceitual:

`common.hero.title`

`common.hero.description`

`common.hero.cta`

`services.title`

`services.description`

`contact.title`

etc.

A arquitetura deve ser escalável.

---

# 16. ESTRUTURA DE TRADUÇÕES

Exemplo:

```text
    about.json
    solutions.json
    services.json
    contact.json

  /en

    services.json

    home.json
    about.json
    solutions.json
    services.json
    contact.json

  /fr
    common.json
    home.json
    about.json
    solutions.json
    services.json
    contact.json
```

Adaptar a estrutura ao framework/biblioteca i18n já utilizada no projeto.

Se já existir uma implementação i18n, **aprimorar a existente em vez de criar outra paralela**.

# 21. PERSISTÊNCIA DO IDIOMA

Ao selecionar um idioma, o website deve manter essa preferência durante a navegação.

Se o projeto utilizar URL-based localization, utilizar uma estrutura consistente.

Exemplo:

`/pt/...`

`/en/...`

`/es/...`

`/fr/...`

OU utilizar a estratégia de routing i18n já adequada ao framework.

Não misturar estratégias.

O idioma selecionado deve continuar funcionando quando o utilizador:

* muda de página;
* abre uma solução;
* abre um produto;
* entra em Contactos;
* utiliza o botão voltar;
* atualiza a página.
